# Unique value proposition

Updated 18 Nov 2026.

**Tagline (chosen by the owner, 49 characters):** Fire data in one place, plus tomorrow's fire risk

Alternatives considered:
- "Predicts tomorrow's wildfires anywhere on Earth" (47);
- "Next-day wildfire risk for utilities and insurers" (49);
- "25 years of fire data and tomorrow's fire risk" (46).

**One-line pitch:** Emerge puts all wildfire data in one place and predicts where new fires are likely to start tomorrow. On data it never saw, it catches nearly twice as many new fires as NASA's fire-weather index `[V]`.

## Claims that hold

- **One harmonized MODIS + VIIRS record from 2000 to today,** for any point or drawn area. Existing tools show the two sensors side by side ([`../../docs/research/competitors.md`](../../docs/research/competitors.md)).
- **We predict before ignition,** while cameras (Pano AI) and satellites (OroraTech) detect fires that are already burning.
- **Software only, on free data:** cheap to serve.

## Claims to avoid

- **"Better than Technosylva or OroraTech":** they publish no accuracy, so it can't be proven ([`../competition/README.md`](../competition/README.md)).
- **"Better than NASA's prediction model":** NASA's index is a weather index, not a fire-prediction model.
- **"We publish our accuracy" as a differentiator:** the owner judged it weak, so it was dropped. Use testing on unseen data as a trust point instead.
- **"We cover Europe" against Technosylva:** it started in Spain and serves Spanish regions.
- **"Solves" the firefighter's problem:** one test year shows progress, not a solution. Say "tackles".
